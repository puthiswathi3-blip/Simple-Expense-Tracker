##### **Simple Expense Tracker**



###### **Project Description**

The Simple Expense Tracker is a Python-based application that helps users record and manage their daily expenses. It stores expense details such as date, category, description, and amount, and generates spending summaries.



###### **Objectives**

\- Record daily expenses.

\- Store expense data permanently using a JSON file.

\- Generate category-wise spending summaries.

\- Calculate total and average spending.

\- Validate user inputs and handle errors.



###### **Technologies Used**

\- Programming Language: Python

\- Data Storage: JSON

\- Modules: `json`, `os`, `datetime`, `collections`



###### **Features**

\- Add new expenses.

\- View all recorded expenses.

\- Display category-wise spending.

\- Generate a total spending report.

\- Validate dates and amounts.

\- Save expenses for future use.

\- Handle invalid menu choices.



###### **Project Structure**

Simple-Expense-Tracker/

│

├── expense\_tracker.py

**Note**: `expenses.json` is created automatically when the first expense is saved.



###### **How to Run**

1\. Install Python on your computer.

2\. Download or clone this repository.

3\. Open a terminal in the project folder.

4\. Run the following command: python expense\_tracker.py

5\. Select an option from the menu to manage your expenses.
